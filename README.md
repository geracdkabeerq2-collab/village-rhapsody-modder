# 乡村狂想曲 · 存档修改器

一个针对 PC 游戏《乡村狂想曲》的本地存档修改工具，提供**悬浮窗版**和**网页版**两种使用方式，支持边玩边改。

> 本工具仅供学习与个人单机使用，请勿用于任何商业或违规用途。

## 功能

| 功能 | 说明 |
|------|------|
| 💰 金钱 | 独立面板，自定义金额（支持到亿），快捷增减 |
| 🎒 道具数量 | 支持从全部道具中任选自定义数量，也可一键批量设置 |
| 💗 NPC 好感度 | 26 个 NPC 好感度星级调整（0~5 星），一键满好感 |
| 🖼️ CG 画廊 | 一键解锁全部 CG |
| ⚡ 体力补满 | 一键补满体力至上限 |

## 使用方式

### 方式一：悬浮窗（推荐，边玩边改）

双击 `启动悬浮窗.bat`，会弹出一个**置顶悬浮窗**，悬浮在游戏窗口上方，可拖拽。

> 依赖：Windows + `pywebview`（基于系统自带 WebView2 Runtime）。

### 方式二：网页版

1. 双击 `启动修改器.bat`
2. 自动打开浏览器界面，操作即可

## 重要提示

⚠️ **修改前务必完全退出游戏**，改完再启动游戏进入存档。游戏运行中修改会被内存中的旧数据覆盖。

## 原理

游戏基于 Cocos Creator 开发，存档为明文 JSON（`data/villagedb_*.qt`），结构为 `{version, datas:[{key,val},...]}`。

修改器解析并修改以下字段：

- 金钱/道具：`knapData_100001.props[]` → `{id, num}`
- 好感度：`npcData_100001.npcDatas[]` → `starNum`
- CG 画廊：`gameData.unlockCgList[]`
- 体力：`attributeData_100001.attrbuteList[]` → `{id:1, num}`

**读档机制（关键）**：游戏读档时同时读取浏览器 localStorage 和 `.qt` 文件，比较两者的 `version` 字段，采用更高的一份。因此修改器每次写回时自动把 `version` 提高，确保文件修改永远优先于旧缓存生效。

## 文件说明

- `启动悬浮窗.bat` / `启动修改器.bat` —— 一键启动脚本
- `floating.py` / `floating.html` —— 悬浮窗版程序
- `server.py` —— 网页版本地后端服务
- `modder_core.py` —— 存档读写核心逻辑
- `modder_data.json` —— 道具 / NPC / CG 名称映射数据
- `modder.html` —— 网页版界面
- `使用说明.md` —— 详细使用说明
